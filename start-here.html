ParkingPocket for GitHub Pages

  1. Extract this ZIP and upload the contents of ParkingPocket-GitHub-Pages to the repository root. Keep index.html at the top level and keep the vendor folder intact.
  2. In your repository, go to Settings → Pages. Choose Deploy from a branch, then select main and /(root).
  3. Open your published HTTPS address. Use Add Ticket to scan a QR, import a photo, or paste a UTSA ticket URL.

The app keeps tickets on this device and shows the saved QR inside the app. A supported price lookup saves the quote, transaction ID, and payment settings. Checkout uses those saved values and talks directly to Authorize.net and the parking API.

Live API limit. The pricing API returned HTTP 403 to a browser preflight for https://iloveparkinggarages.github.io. Ticket scanning and local storage work. Live recheck and checkout require the parking service to allow requests from that origin. The ZIP includes the direct API code and does not redirect to the parking site.
